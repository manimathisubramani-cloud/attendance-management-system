# Attendance Management System

A web-based Attendance Management System built using the MERN stack.

## Features

- Add students
- Edit student details
- Delete students
- Calculate attendance percentage
- Eligible / Not Eligible status
- Daily Present / Absent attendance
- Search students by name or register number
- Dashboard with attendance statistics
- MongoDB database storage

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- CSS
- Vite
